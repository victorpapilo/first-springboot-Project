# Peak Hospital

A hospital management system built to handle patient records, visits, and revenue tracking for both new and returning patients.

## Project Status

🚧 **In Development** — this README defines the project scope. Implementation is starting next.

## Why This Project

Real-world hospitals need a reliable way to manage patients, appointments, and income. Building Peak Hospital is a hands-on way to prepare for handling real-life healthcare/management systems — practicing the full stack from database design to a working admin dashboard.

## What It Does

Peak Hospital helps a hospital:

- Register and manage **new patients**
- Track **returning/recurring patients** and their visit history
- Keep an overview of the **hospital's overall patient records**
- Track **income/revenue** generated from patient visits and services

## Core Features (Planned)

- **Admin Dashboard** — central overview for hospital staff/admin
- **Patient Check-In Tracking** — number of patients checked in (daily/weekly/monthly)
- **Revenue Tracking** — income generated from patients over time
- **Patient Records Management** — create, view, update patient profiles (new vs. recurring)
- **Reports/Analytics** — summarized stats on patients and revenue (stretch goal)
